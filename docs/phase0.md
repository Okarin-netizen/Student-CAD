# フェーズ0: 技術検証

計画ドキュメント: https://claude.ai/artifact/XT2RhuNKccpJr8WNEXvwmz

## 確かめたいこと

学校のタブレット(iPad の Safari、Chromebook の Chrome)で、次の3つが授業に使える速さで動くかを確かめます。

1. 3D形状カーネル OpenCascade(WebAssembly、約23MB、gzip後 約7.3MB)が読み込めて、メモリ不足で落ちないか
2. 拘束ソルバ planegcs で、寸法を変えたときにスケッチが追従するか
3. スケッチ → 押し出し → 角の丸み → STL 書き出し が、指の操作に遅れずについてくるか

## 検証用アプリの中身

「穴あきプレート」(キーホルダーの土台)を1つだけ作れるアプリです。

- 左: スケッチ(2D)。右上の角と穴の中心を指でドラッグできる(0.5mm ごとに吸い付く)
- 右: 立体(3D)。1本指で回す、2本指で動かす・拡大
- 下: 寸法の入力(よこ・たて・あつみ・穴の直径・穴の位置・角の丸み)と STL 書き出し
- 一番下: 計測結果。起動時間、WASM の通信量、計算時間、連続テスト(20回)の結果

形の決め方は Onshape/SolidWorks のスケッチと同じで、点と線に「水平」「垂直」「原点に固定」の拘束と寸法を付け、planegcs に解かせています。
重い計算はすべて Web Worker で行うので、計算中も画面の操作は止まりません。

## 実機での計測手順

1. GitHub Pages に公開されたページを、iPad(Safari)と Chromebook(Chrome)で開く
2. 「準備完了」になるまでの時間を見る(初回とページ再読み込み後の2回)
3. 角や穴を指でドラッグし、立体が遅れずについてくるか、指で操作しやすいかを確かめる
4. 「連続テストを実行」を押す
5. 「3Dプリント用に書き出す(STL)」を押し、ファイルが保存できるかを確かめる
6. 「計測結果をコピー」を押して、結果をスレッドに貼り付ける

## 合格の目安(確認点)

| 項目 | 目安 |
| --- | --- |
| 初回の準備完了まで | 学校の Wi-Fi で 30 秒以内 |
| 2回目以降の準備完了まで | 5 秒以内 |
| 連続テストの平均 | 300 ms 以内(ドラッグが遅れて感じない) |
| 連続テストの失敗 | 0 回 |
| 操作中にタブが落ちる | 0 回 |

目安に届かない場合は、OpenCascade の機能を絞ったカスタムビルドや、メッシュ演算ライブラリ Manifold への切り替えを検討します。

## 実機の結果(2026-11-05)

`?bench` のページ(連続テスト 20 回)で測りました。3機種とも目安に届いています。

| 端末 | 準備完了まで | 連続テストの平均 / 最大 | 失敗 |
| --- | --- | --- | --- |
| iPad mini(iPadOS 18.7 Safari、キャッシュあり) | 0.97 秒 | 23 ms / 57 ms | 0 回 |
| Windows PC(Chrome) | 3.0 秒 | 41 ms | 0 回 |
| Chromebook(ChromeOS、2コア・4GB、キャッシュあり) | 2.0 秒 | 82 ms / 151 ms | 0 回 |

計測用のページは、本体の公開後も `/?bench` で開けます。
