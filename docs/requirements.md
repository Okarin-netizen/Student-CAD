Student-CAD が「何を満たせば よいか」の一覧です。機能を足す・やめるときは、ここに行を足すか、状態と理由を書きかえてください。

- 状態: 候補 → 承認 → 実装中 → 実装済み → 検証済み(本物の生徒・先生・実機で確かめた)。ほかに 見送り・保留
- 優先度: Must(ないと授業で使えない)/ Should(あると授業が楽になる)/ Could(あればよい)
- 確かめ方の `e2e/○○` は `tests/e2e/○○.spec.ts`、`unit/○○` は `tests/unit/○○.test.ts`

## 受入条件(授業で使ってよいかの基準)

数字は仮の値です(2026-11-23 点検の文書の案)。先生が決めたら「承認」にします。

| ID | 条件 | 状態 |
| --- | --- | --- |
| A-01 | CAD が初めての生徒 5人中 4人以上が、先生の説明 10分のあと 40分以内に、名札の課題を提出 ZIP まで出せる | 候補 |
| A-02 | その生徒が「寸法を変えると形が変わる」ことを、自分の言葉で説明できる | 候補 |
| A-03 | iPad(Safari)・Chromebook(Chrome)の実機で、指だけで A-01 の課題が最後までできる | 候補 |
| A-04 | 30台が同時に開いても、教室のネットで準備完了まで 30秒以内(2回目からはオフラインで開く) | 候補 |
