# 使っているライブラリと、これからの見通し

2026-11-22 に点検した結果です(おかだ さんの依頼「古いライブラリを使っていないか、今後の発展性を考えて確認して」)。
次に点検するときは、`npm outdated` と `npm audit` を実行して、この表を書きかえてください。

## まとめ

- 古くなったライブラリや、開発が止まったライブラリはありません。`npm audit` の弱点(脆弱性)も 0 件です。
- 小さな更新(vite 8.3.8・vitest 5.1.1・@vitejs/plugin-react 6.3.0)は、この点検で入れました。
- GitHub Actions の部品が古い版(Node 20 で動くもの)だったので、新しい版(Node 24)にしました。CI の Node も 22 から 24 にしました。
- 大きな更新(下の「これからの候補」)は、動きが変わるおそれがあるので、まだ入れていません。

## これからの候補(大きな変更なので、やるかどうかは相談して決める)

1. **OpenCascade(replicad-opencascadejs)を 1.2 に上げる**: 新しい OpenCascade の直しが入る。iPad・Chromebook で `?bench` の速さと、読み込む大きさを前と比べてから入れる。
2. **TypeScript 7 に上げる**: 型チェックが速くなる。`tsconfig.json` の設定の見直しがいる。
3. **ESLint を入れる**: いまはコードの書き方を自動で確かめる道具がない(コードの中の `eslint-disable` のコメントは、前に入れるつもりだった名残り)。入れると、React の useEffect の書きもれなどを自動で見つけられる。
4. **大きなファイルを分ける**: `app/sketch/SketchEditor.tsx`(約 1,200 行)と `app/app.css`(約 2,600 行)が大きい。機能を足すときに、その部分から少しずつ分けていく(一度に分けると、画面の動きが変わったことに気づきにくいため)。
5. **PWA(ネットなしで開ける)**: 2026-11-23 に入れた(ライブラリは使わず、pwa/service-worker.js を自分で書いた)。
