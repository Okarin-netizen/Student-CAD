# Student-CAD

中学生がタブレット(iPad / Chromebook / Windows タブレット)のブラウザだけで使える、2D・3D CAD を目指すプロジェクトです。
操作の考え方は Onshape や SolidWorks と同じ「スケッチ → 寸法と拘束 → 押し出し → 作業のれきし」にして、
将来プロ向けの CAD にそのまま移れるようにします。

- 開発計画: https://claude.ai/artifact/XT2RhuNKccpJr8WNEXvwmz
- いまの段階: **フェーズ1(最初に使える版)**。フェーズ0(技術検証)の結果は [docs/phase0.md](docs/phase0.md)

## できること(フェーズ1)

1. **絵をかく(スケッチ)**: 上の面・正面・右の面、または立体の平らな面を選んで、線・長方形・円・円弧・多角形をかく
   - 寸法(長さ・距離・直径・角度)は大きな数字キーで入れる。「100/2」のような式も使える
   - きまり(拘束): 水平・垂直・くっつける・平行・直角・同じ長さ、補助線
   - あといくつ決めれば形が決まるかを表示し、決まると「🔒 形がすべて決まりました」
2. **立体にする(押し出し)**: あつさを入れて「くっつける」か「けずる」。向きの反対も選べる
3. **書き出す**: STL・3MF は 3Dプリンターのソフトで、STEP は Onshape・SolidWorks・Fusion などで開ける

フェーズ2で追加:
- **回転**: 補助線(または原点を通るたて・横の軸)のまわりにスケッチを回して、コップやコマのような形を作る。角度も選べる
- **角を丸める / 角を落とす(フィレット / 面取り)**: 3D で辺をタップしてえらび、大きさを入れる。寸法を変えても、近い辺を探して丸め続ける
- **文字(名札)**: スケッチの「文字」で名前を置き、押し出してくっつける(浮き出し)かけずる(彫る)。面からはみ出すと、入る大きさに直す
- **対称にする(ミラー)**: 立体ぜんぶ、または1つの作業(穴など)を、上・正面・右の面を鏡にして写す
- **ならべる(パターン)**: 穴などを、まっすぐ(2方向で格子にも)か、円のまわりにならべる
- **名前つきの数(変数)**: 「幅 = 40」のように数に名前をつけて、寸法やあつさに「幅/2」のように使う。数を変えると全部いっしょに変わる
- **図面**: 立体から第三角法・等角図・キャビネット図をかく。かくれ線・寸法・穴の中心線・表題欄つきで、SVG・DXF・印刷(PDF)にできる。レーザー加工用の 1:1 DXF も出せる

フェーズ3(先生の機能)で追加:
- **課題**: 先生が説明と自動で確かめる条件(大きさ・体積・使った作業)を入れて課題ファイルを配る。生徒の画面の課題カードに、できた条件は ✓ がつく。名札・コースター・ペン立て・キーホルダーのひな形つき
- **提出用ファイル**: 作品・STL・図面・見た目の絵・提出カードを、組・番号・名前つきの ZIP にまとめる
- **作り方の再生**: 作った順に、形ができていく様子を見る
- **作業時間の記録**: 作り始めた日と作業していた時間を作品ファイルに残す
- **使い方ガイド**: はじめて開いたとき、押すボタンを光らせながら板を作って角を丸めるまでを案内する

フェーズ4(発展)で追加:
- **面をずらしてかく**: 基準の面から ○mm ずらした面にかく
- **つなぐ(ロフト)**: 高さのちがう面にかいた形をなめらかにつなぐ(四角から円へ、など)
- **くりぬく(シェル)**: 面をタップして取りのぞき、中をからにする(ペン立て・コップ)
- **なぞる(スイープ)**: 断面の形を線(道すじ)にそって動かす(取っ手・パイプ・リング)

ほかに、作業のれきし(あとから寸法をなおすと形が作り直される)、もどす/やりなおす、
端末の中への自動保存、作品ファイル(.scad.json)の保存と読み込み、専門用語への切り替えがあります。

操作: 1本指で回転、2本指で移動・拡大(3D)。スケッチでは2本指で移動・拡大、何もないところのドラッグで移動。
キーボードでは Ctrl+Z / Ctrl+Shift+Z も使えます。

## 仕組み

| 層 | 使っているもの |
| --- | --- |
| 画面 | React + TypeScript(Vite) |
| 3D描画 | three.js |
| 3D形状計算 | replicad + OpenCascade(WebAssembly) |
| 2D拘束計算 | planegcs(FreeCAD のソルバの WebAssembly 版) |
| 計算の実行場所 | Web Worker(画面を止めない) |
| 保存 | 端末の中(IndexedDB)とファイル。アカウントやサーバーは使わない |

サーバーは使わず、ブラウザの中だけで動きます。

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # 単体テスト(拘束計算・立体化・STL)
npm run test:e2e   # iPad 横向き・Chromebook の画面サイズでの操作テスト
npm run build
```

`main` に入ると GitHub Actions で GitHub Pages に公開されます(初回のみ、Settings → Pages の Source を「GitHub Actions」にしてください)。

変更履歴は [CHANGELOG.md](CHANGELOG.md) にあります。
